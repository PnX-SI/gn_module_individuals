# Module Individuals

Ce module de GeoNature permet la gestion des individus (faune).

Dans ce module nous pourrons donc :

1) Gérer une liste d'individus

Est entendu par 'individu', tout animal pouvant être individuallement suivi via un mode d'identification (marques, emetteur, analyses génétiques ...). Il est possible de
- Ajouter, modifier et supprimer un individu
- Consulter de cette liste
- Consulter de la fiche descriptive d'un individu

2) Gérer une liste de dispositifs de suivis

Est entendu par 'dispositif de suivi', tout système permettant l'identification et la reconnaissance d'un individu : marquage, décoloration, émetteur, ... Il est possible de

- Ajouter, modifier et supprimer un dispositif de suivi
- Consulter de cette liste
- Consulter de la fiche descriptive d'un dispositif de suivi

3) Gérer les déploiements réalisés sur un individu

Est entendu par 'déploiement', l'évènement permettant d'équiper un individu d'un ou plusieurs dispositifs de suivi à un moment donné. Il est possible de

- Ajouter, modifier et supprimer un déploiement
- Consulter la liste des déploiments pour un individu donné
